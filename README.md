# iCodeThis Challenges

This repository collects standalone UI components and solutions for front-end challenges on [iCodeThis](https://icodethis.com/). Each component lives in its own directory with a self-contained `index.html`, `style.css`, and `script.js` — no build tools, no frameworks, just open the HTML file.

- [My iCodeThis Profile](https://icodethis.com/Andre_Marinho)

## Components

| Component | Description |
|---|---|
| [card-hover-effect](card-hover-effect/) | Pointer-following hover animation for interactive cards |
| [chip-navigation](chip-navigation/) | Horizontal scrolling chip tabs linked to page sections with scroll sync |
| [content-toggle](content-toggle/) | Multi-panel toggle with keyboard navigation and fade transitions |
| [feature-carousel](feature-carousel/) | Pointer-based drag carousel with synced cards, dots, and mobile card swiping |
| [logo-carousel](logo-carousel/) | Continuously looping logo strip that slows on hover |
| [mobile-menu-toggle](mobile-menu-toggle/) | Hamburger button with slide-in navigation panel |
| [password-field](password-field/) | Password input with visibility toggle and stay-signed-in switch |

## Useful Resources

These assets are handy for rapidly prototyping UI elements during the challenges:

- [Pravatar](https://pravatar.cc/) – placeholder avatar images.
- [Picsum](https://picsum.photos/images) – royalty-free placeholder photography.
- [SVGL](https://svgl.vercel.app/) – curated SVG icon library.
- [Tabler Icons](https://tabler-icons.io/) – versatile open-source SVG icon set.
